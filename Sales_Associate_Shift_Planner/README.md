# Sales Associate Shift Planner – Excel Dashboard

## Overview
This project is a weekly shift planning dashboard built in Microsoft Excel for sales associates in a retail store. It helps assign employees to shifts, track weekly hours, and identify scheduling conflicts.

## Objective
To create a simple and professional Excel-based scheduling tool that improves workforce planning and highlights overtime, double shifts, and availability issues.

## Files / Sheets
- Employees: Employee master data including availability and weekly hour limits.
- Shifts: Shift timings and schedule settings.
- Schedule: Weekly shift planner with employee assignments.
- Dashboard: KPI summary and charts.

## Features
- Employee dropdown selection for shift assignment
- Automatic calculation of total hours and overtime
- Conflict detection for double shifts and availability violations
- KPI cards and charts for schedule analysis

## Tools Used
- Microsoft Excel
- Formulas
- Data Validation
- Conditional Formatting
- Charts

## Key Outcome
This project creates a clean weekly schedule view and a dashboard that helps track staffing workload and scheduling issues at a glance.

## How to Use
1. Open the Excel file.
2. Enter or update employee details in the Employees sheet.
3. Assign employees in the Schedule sheet using dropdowns.
4. Review the Dashboard for KPIs and conflict counts.
